# 來打我啊 笨蛋

第一視角的舒壓小遊戲，單一 HTML 檔，不需安裝、不需登入。

## 玩法

1. 選你要揍誰、你是什麼角色、要不要用武器、怒氣值多少。
2. 倒數 3 秒後開打。
3. 手機：點左半邊出左拳，點右半邊出右拳。電腦：← → 出拳，↑ 召喚獸，↓ 翻桌。
4. 怒氣滿了可以翻桌；每打完三場得到一次召喚獸。
5. 打完可以做一分鐘呼吸，比較打之前、打完、呼吸後的怒氣分數。

## 隱私

- 上傳的照片只留在瀏覽器記憶體，不上傳、不儲存，關掉頁面就消失。
- 場數與連續天數只存在這台裝置的瀏覽器。

## 執行

直接用瀏覽器開啟 `index.html`，或透過 GitHub Pages 開啟。
